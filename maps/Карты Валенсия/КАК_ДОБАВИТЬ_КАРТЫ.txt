КАРТЫ ПОЛЕЙ БОЯ ДЛЯ ГЕКСОВ ОПЕРАТИВНОЙ КАРТЫ (v13.049, R34)
==========================================================

Как это работает
----------------
Когда начинается тактический бой на гексе оперативной карты (например 8,10),
игра открывает карту поля боя из ЭТОЙ папки — файл, имя которого начинается с
номера гекса в виде «8.10»:

    maps/Карты Валенсия/8.10 мост.json        → бой на гексе (8,10)
    maps/Карты Валенсия/12.14 переправа.json  → бой на гексе (12,14)

Подходят форматы имени:  8.10 ... / 8,10 ... / 8-10 ...
Формат самого файла — как у карт, сохранённых из редактора игры
(«Экспорт карты»): { "templates": [...], "currentMap": { "grid": { "0,0": {...} } } }.

Если карты для гекса нет — тактический бой идёт на обычном поле 20×20 (как раньше).


Шаг 1. Положить файлы карт в эту папку.
Шаг 2. Собрать индекс (список карт), один раз после добавления/переименования:

    node tools/build_hex_map_index.js

Появится файл maps/Карты Валенсия/index.json — по нему игра находит карту гекса.
Без индекса игра всё равно попробует файлы «8.10.json» и «8,10.json».


Правки местности на карте гекса (сохраняются у обоих игроков)
-------------------------------------------------------------
1) ОКОПЫ. Приказ «🕳️ Окопаться» выполняется 3 хода. По завершении игрок получает
   по 1 гексу окопа за каждый отряд взвода, который окапывался. Кнопка
   «🛠️ Карты гексов» в панели «🗺️ Вид и настройки карты» (или кнопка в сообщении
   после окапывания) открывает карту этого гекса в режиме редактора: клик по гексу
   «трава»/«дорога» ставит окоп. Кусты, лес, болото, камни, склон холма менять
   на окоп нельзя. Повторный приказ «Окопаться» даёт новые гексы окопов.

2) ПОДГОТОВКА ПОЗИЦИЙ. Новый приказ «🪓 Подготовка позиций» (3 хода, только пехота).
   По завершении — по 1 правке за каждый отряд взвода: «лес» (лес1, лес2) →
   «поваленный лес» (обзор открыт), «кусты» (кусты1, кусты2) → «трава».
   Это открывает секторы стрельбы: из стрелкового оружия нельзя стрелять по цели,
   которая находится в лесу глубже 2 гексов (ПТО и орудия — могут).

3) ВОРОНКИ ОТ ОБСТРЕЛОВ. Каждый обстрел гекса средней/тяжёлой артиллерией
   (миномётная батарея, САУ, артиллерия >70 мм) добавляет на тактической карте
   этого гекса 5 гексов: вместо леса — «обстрелянный лес», вместо травы/кустов —
   «воронки в поле» (рядом с окопами — в первую очередь). Воронки дают укрытие
   как камни (+2 к сложности попадания) и проходимы как камни (пехота 4 ОД,
   техника не заходит).

Все правки хранятся в кампании (hexOverlays) и в онлайне передаются оппоненту —
при бое на этом гексе он видит те же окопы, вырубки, воронки и обстрелянный лес.
