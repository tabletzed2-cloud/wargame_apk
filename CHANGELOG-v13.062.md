# Боевой модуль v13.062

Дата: 2026-10-05. Проверка 22 замечаний к v13.061 и уточнённых правил.
Рабочие имена HTML/JS сохранены; версия отмечена в изменённых файлах,
интерфейсе приложения, manifest и имени офлайн-кэша.

## Согласованные правила

- БеВе: пять тактических карт перед окончанием начальной расстановки;
  до **8 стартовых клеток окопов на каждой карте**.
- Завершённый приказ «Окопаться»: **одна дополнительная клетка на живое
  отделение/расчёт взвода**. Например, 6 отделений дают 6 правок, независимо
  от стартовых восьми. Повторные клики меняют текстуру, а не создают новые очки.
- Ночь: **23:00–05:00**, включая начало сценария в 00:00.
- Красный тактический дух: автоматическое движение к своему краю карты
  **за оставшиеся ОД в свою фазу**; до выхода отряд остаётся целью.
  Если пути нет, отряд не телепортируется. Порог тактического духа — 1,
  оперативного — 25/100 (существующая красная зона).
- Недоступная промежуточная точка приказа обходится. Если недоступна сама
  конечная клетка, выбирается достижимая соседняя клетка; за пределами карты
  маршрут не принимается.

## Проверки

Запускать последовательно: исторические Node-песочницы используют общий
временный файл `/tmp/wg_part.js`.

```sh
node 'test_harness /checkhtml.js'
node 'test_harness /regression_v13061.js'
node 'test_harness /regression_v13062.js'
node 'test_harness /sim_online2.js'
node 'test_harness /t_standalone.js'
```

Результаты:
- 4 встроенных блока JavaScript: синтаксических ошибок нет.
- 13 проверок исходного исправления (ожидание лимита окопов обновлено по уточнению).
- 21 новая проверка правил, включая обмен тактическими снимками между двумя VM-клиентами.
- 37 существующих проверок оперативной онлайн-синхронизации.
- Проверка добавления отрядов одиночного боя: без исключений.
- `test_harness /browser_v13062.cjs`: загрузка полного HTML/JS в Chromium,
  кнопка/блокировка спешивания, две фазы (00:00 → 00:02 → 00:04), запрет
  чужого хода, сохранение ОД, создание боя группы техники на гексе защитника
  и расход снарядов при выстреле. Ошибок страницы нет.

Браузерный тест требует установленного `playwright` и Chromium:

```sh
# Playwright и браузер устанавливаются отдельно, не добавляются в репозиторий.
CHROMIUM_PATH=/path/to/chromium node 'test_harness /browser_v13062.cjs'
# Если Playwright уже установил Chromium, CHROMIUM_PATH можно не задавать.
```

**Границы проверки:** это автоматические проверки правил, симуляция обмена
снимками и локальный Chromium, не полный матч двух физических Android-устройств
с боевым Firebase. Сборки APK в этом репозитории нет: он содержит веб-приложение/PWA.
После обновления обоим игрокам следует нажать «Обновить игру» и проверить
надпись v13.062. Для приёмочного матча рекомендуется новая кампания: уже
истраченные/неправильно выданные ресурсы старого сохранения автоматически
не пересчитываются.
