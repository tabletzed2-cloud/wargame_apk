# v13.164 — разведприказы: Hidalgo у штаба, развед. взвод, свои активы, БА BeVe

Четыре замечания по выдаче приказов на разведку.

**1. У штаба батальона A.I.R.F. не выбирался Hidalgo** — приказ на разведку отдать
было нельзя, а у самого Hidalgo в расчёте было 0 бойцов вместо 2.
**2. То же у развед. взвода A.I.R.F.**
**3. В карточке каждого взвода** показывались чужие разведчики («Доступно:
мотоциклист, Hidalgo…»), хотя выдать им приказ этот взвод не может.
**4. У BeVe не было приказа на разведку для бронеавтомобилей.**

## Причины

* **Пул активов не пересчитывался.** `campaign.reconAssets` строился один раз
  (`initReconAssets`) и только при пересборке юнитов. У начатого похода после
  чистки состава (v13.161 — Hidalgo/мотоциклисты переехали в штаб) пул оставался
  от прежнего состава: `total = 0`, значит актив не попадал ни в карточку, ни в
  панель, и `createReconMission` отвечал «актив недоступен».
* **Отряд при штабе добавлялся «пустым».** `pruneOpUnitRiders` создавал
  `{ name, templateName }` без шаблона — у Hidalgo не было ни водителя, ни
  наблюдателя, ни иконки, ни боезапаса.
* **Карточка показывала общий список.** `reconButtonMarkup` брал
  `getReconAssetList(unit)`, который возвращает активы всего батальона (переданный
  юнит лишь сортировался первым).
* **Бронеавтомобиль был исключён из активов** решением v13.160.

## Что изменилось

### Пул активов (`js/recon.js`)

* новая `syncReconAssetPool()` — пересчёт `total/available` из фактического
  состава войск с учётом `reconLost` и активных миссий;
  `initReconAssets()` теперь просто вызывает её;
* пересчёт выполняется перед каждым обращением: `getReconAssetList`,
  `getOwnReconAssetList`, `createReconMission`, а также при загрузке похода —
  после `pruneOpUnitRiders()` (index.html). Устаревший пул сам «лечится».

### Отряды разведки при штабе (`index.html`)

* `opReconSquadInstance(faction, name, templateName)` — отряд собирается по
  шаблону (`cloneTemplate`), т.е. со бойцами, боезапасом и иконкой;
* `opRepairSquadFighters(squad, faction)` — если отряд уже лежит в сейве
  «пустым», расчёт возвращается из шаблона;
* в `pruneOpUnitRiders` оба шага применяются к отрядам штаба, поэтому
  **у AL-41 Hidalgo снова 2 бойца — водитель и наблюдатель** (и иконка
  `images/AIRF/Hidalgo GL-41.png`).

### Карточка юнита — только свои активы (`index.html`)

* `reconButtonMarkup` строится по `getOwnReconAssetList(unit)`
  (`reconAssetSourcesForUnit` — отряды/машины ИМЕННО этого юнита);
* у взвода без своих разведчиков блока «🔍 Разведка» нет вообще;
* у штаба батальона — своя кнопка на каждый его развед-отряд (мотоциклист,
  Hidalgo); у развед. взвода / его отделения / бронеавтомобиля — своя кнопка;
* актив на задании показывается неактивной кнопкой «— на задании»
  (`reconUnitOnMissionAssetKeys`).

### Бронеавтомобили BeVe снова с разведкой

* новый тип актива `beve_armored_car` («Бронеавтомобиль Landsverk 183»,
  подвижность дорога/трава/кусты 4, лес — нельзя);
* `reconStandaloneKeyForUnit` узнаёт отдельную машину (Landsverk / «Бронеавтомобиль»);
  слитые группы («Отряд Бронеавтомобиль (2шт)») и танки активом не считаются;
* в миссию уходит САМА машина (не отряд при штабе): юнит помечается
  `reconMissionId`, скрывается с карты и едет по маршруту; после отправки
  приказа выбор с него снимается.

### Прочее

* `isBattalionHqUnit` узнаёт штаб батальона и с суффиксом в имени
  («Штаб Батальона A.I.R.F.») — в старых сейвах штаб мог называться иначе, и
  тогда Hidalgo с мотоциклистами не находили своего места;
* `getOwnReconAssetList` / `reconAssetSourcesForUnit` / `reconUnitOnMissionAssetKeys`
  — новый API для карточек;
* версия: `APP_VERSION` / `CACHE_NAME` / `manifest.short_name` / BUILD-маркеры
  `js/*.js` → v13.164.
