# v13.200 — сохранения, транзакции, офлайн-обновление и проверки

## Исправления

- Ошибка загрузки больше не удаляет сохранение: исходный JSON сохраняется, автосохранение блокируется до восстановления/явного сброса, доступен экспорт копии.
- Ошибка localStorage/QuotaExceededError больше не сопровождается ложным успехом; saveData возвращает результат, игрок видит предупреждение.
- Импорт проверяет основные структуры, делает копию прежних данных и записывает JSON непосредственно, без перезаписи импортированных Hard Mode/тактических данных прежними глобальными переменными. Pagehide не затирает импорт перед перезагрузкой.
- Журналы ограничивают HTML простым форматированием без атрибутов; рассмотренные сообщения карты, названия шаблонов, состав батальона и иконки активных карт защищены экранированием/URL-фильтром. Это частичная защита, не завершённый аудит всех редакторов.
- Создание комнаты не перезаписывает существующий код; занятие p2 и смена хода выполняются транзакциями. Сохраняется роль при переподключении, игнорируются запоздавшие callbacks прежней комнаты.
- Сбой расчёта маршрута очищает подсветку/пути и показывает ошибку вместо молчаливого catch.
- Все runtime-скрипты/стили обязательны в офлайн-кэше; собственные JS проверяются по маркерам версии. Чужие кэши origin не удаляются.

## Разработка

- Удалены ранние дубли tacticalSquadHexPosition/useAdrenaline с сохранением реальных последних реализаций.
- Acorn вместо подсчёта фигурных скобок при извлечении функций для тестов.
- Удалено неявное исполнение общего /tmp/wg_part.js; legacy-тесты переведены на явный локальный prelude. Таймеры песочницы не глотают исключения; доступны strictDOM/strictRules.
- Каталоги `test_harness/` и `tools/` больше не имеют завершающих пробелов.
- Добавлены package.json/lockfile, единые команды проверок, корректный exit code проверки сборки и GitHub Actions.
- Добавлены README, CONTRIBUTING, инструкции восстановления и документирование оставшихся сетевых рисков.

## Проверки

- `npm test`: 10/10 smoke-скриптов, синтаксис, зависимости и версии — PASS.
- `npm run test:browser`: движение всех восьми Landsverk/CL39 и пиксели секторов; реальные DOM-проверки; повреждённый JSON, file-input импорт, pagehide/reload; настоящий SW с отказом обязательного ресурса и последующим офлайн-запуском — PASS.
