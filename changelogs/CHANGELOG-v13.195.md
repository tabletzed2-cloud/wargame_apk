# v13.195 — исправления плейтеста тактического боя и кампании

- Повторная расстановка остаётся доступной до подтверждения фазы; подкрепления используют полосу края, соответствующую направлению прибытия.
- Отход по низкому духу завершается выходом через край; сдача за заблокированный отход разрешена только при духе 0–10%. У штаба сохраняется восстановление духа.
- Линии огня отображаются пунктирными стрелками без подписей отрядов. Иконки штабов рот получают серебряную рамку, батальонные штабы — золотую.
- Необнаруженные/замаскированные цели остаются недоступными; несколько вражеских отрядов в одном гексе выбираются как отдельные цели.
- Для пулемётов амбразур добавлен выбор сектора; BeVe Landsverk может вести огонь 37-мм орудием с расходом снарядов и сохраняет профиль секторов машины.
- По завершении боя открывается сводка потерь обеих сторон и бойцов по отрядам. При потерях не менее половины можно вручную перенести уцелевших в совместимый повреждённый отряд подходящей вместимости.
- Оптимизирован повторный расчёт достижимости транспорта в панели снабжения; закрытие вкладки не инициирует скрытую перерисовку.
- Проверены исполнение приказа через штаб роты подчинённым взводом и разрыв телефонной линии по фактическому пересечению кабеля.
