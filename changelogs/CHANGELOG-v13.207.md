# v13.207 — паническое бегство и удаление ручного скрытия

## Согласованные правила

- «К штабу: передохнуть» снова недоступно отряду, который уже бежит. Общая проверка действий запрещает как нажатие кнопки, так и прямой вызов исполнителя. Подавленный, но ещё не бегущий отряд может отдыхать по прежним правилам; улучшенный выбор доступного штаба из v13.206 сохранён.
- Автоматическое бегство по духу направлено **к краю, противоположному стороне входа противника**. Направление определяется из записи размещения боя; во встречном бою — из стороны входа оппонента. Оно фиксируется в `map.routExitDirections` и сохраняется вместе с тактической картой, не меняясь вслед за ближайшим врагом.
- Для старых/одиночных карт без записи размещения направление один раз восстанавливается по положению противника и затем фиксируется; при полном отсутствии данных используется стабильное запасное направление для каждой стороны.
- По выбору пользователя зона выхода включает **только крайний ряд**. Для диагональных направлений — наружные клетки соответствующего углового сектора, согласованного с геометрией размещения, не вся граница карты и не два ряда зоны входа.
- Отряд расходует доступные ОД на маршрут и остаётся в тактическом бою до достижения выбранной границы. При достижении вызывается обычное завершение отступления: выжившие сохраняются, статус становится `retreated`, присутствие отряда удаляется из тактических гексов. Автоматического ралли у штаба больше нет.
- Если **любая клетка этой зоны занята живым присутствующим противником**, уже бегущие к ней отряды сдаются. Проверка выполняется при обработке бегства и после реальных шагов движения, а не только в конце фазы. Видимость противника на условие не влияет. Уничтоженные, сдавшиеся, покинувшие карту и временно отсутствующие бойцы не блокируют выход.
- Занятие зоны — новое отдельное основание сдачи бегущего отряда, не требующее обнулённых боеприпасов и духа. Общая сдача не бегущих отрядов по условиям «дух 0 + нет боеприпасов + враг в пределах 3 гексов» не менялась. Сдавшийся остаётся на своём гексе с маркером и не действует.
- Простая непроходимость маршрута вне зоны выхода не подменяет занятие зоны: отряд остаётся в бегстве, не выбирает другой край и не сдаётся автоматически по этому основанию.
- Явный приказ на отступление/выход из боя остаётся отдельной механикой с выбранным игроком направлением, не подменяется паническим бегством. Существующие правила начала бегства, исключения ДОТ/штабов/«Упрямства» сохранены.
- Исправлено попутное восполнение ОД ИИ при `tacticalAP=0` в обработке бегства: ноль больше не заменяется полным запасом.

## «Скрыться»

Удалены кнопка, окно выбора условий, переменная режима и ручные исполнители `showDetectionDialog`, `closeDetectionModal`, `executeDetectionCheck`. Таким образом, повторять бесплатные попытки нельзя и через старый интерфейс, и отдельным вызовом старого API. Автоматическое обнаружение, дым, местность, скрытное перемещение и карточная маскировка сохранены.
