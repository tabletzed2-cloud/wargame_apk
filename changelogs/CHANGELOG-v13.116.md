# v13.116

- Для бронемашин с исправным орудием (ПТО/танковая пушка) в панели стрельбы теперь явно отображается кнопка «Огонь артиллерией · [название орудия]». Кнопка вызывает стандартное действие стрельбы орудиями/миномётами; при отсутствии снарядов она остаётся видимой, но отключается с пояснением.
