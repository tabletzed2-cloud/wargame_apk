# v13.145 — «Перерезать пути» и окружение кольцом

> Релиз включает в себя всё из v13.144 (она не была выпущена отдельно):
> крупные метки/иконки тактической карты, стрелки «кто по кому стрелял»,
> доставка снабжения в обход врага (в том числе в бой), статус «окружён» по
> перекрытым путям отхода на оперативной карте, огнемётная струя, доворот
> бронетехники по курсу каждого шага, дух карточек в очках (0–100),
> «Подготовка местности» по числу отрядов, общий запас патронов взвода.

## 1. Приказ «✂️ Перерезать пути» (оперативная карта)

Новый отдельный приказ в меню «⚙️ Специальное» (только пехота).

* Выбираются **три смежных гекса цепочкой** — «крайний → средний → крайний».
  Каждый следующий гекс обязан примыкать к краю выбранной цепочки; повторный
  клик по гексу снимает его.
* Взвод выдвигается на **средний** гекс цепочки (движение тратит ОД, как у
  любого марша; при нехватке ОД приказ остаётся активным и продолжается в
  следующем ходу).
* Все три гекса помечаются **контролируемыми противником**: через них нельзя
  пройти, на карте они рисуются косым крестом.
* Игрок видит перерезанные гексы и замкнутые кольца из них; противник —
  только последствия.

## 2. Окружение кольцом (оперативная карта)

* Замкнутое кольцо перерезанных гексов вокруг вражеского взвода = окружение.
  Внутренность кольца считается честно, по многоугольнику из центров гексов
  (гексы самого кольца «внутри» не считаются).
* Дух окружённого: **−10 сразу** при замыкании кольца и **−5 за каждый
  следующий оперативный ход**, пока кольцо не прорвано.
* Кольцо прорвано (гекс потерян/взвод перерезания уничтожен) — статус
  снимается, давление на дух прекращается.

## 3. Окружение на тактической карте — новая система (заменяет «≥4 направлений»)

* Окружение — это **кольцо отрядов игрока**: расстояние между соседними
  отрядами кольца **≤4 гекса**, окружённый стоит внутри кольца (проверка по
  многоугольнику, самопересекающиеся кольца отбрасываются).
* Дух окружённых: **−10 сразу** и **−5 за каждую завершённую фазу**, пока
  кольцо не прорвано (не чаще одного раза за фазу).
* **Подсветка цепочки видна только окружающему** (пунктирное кольцо рисуется
  лишь для колец своей стороны); окружённым показывается только уведомление.
* При духе 0 окружённый отряд **сдаётся** — он не отступает и не «бежит».
  ДОТы по-прежнему держатся до конца.
* Старая система «контроль ≥4 направлений отхода» удалена.

## 4. Серия приказов п.2 — только внутри одного хода

* Приказ, отданный в том же ходу, дописывается в серию получателя (одна
  доставка, последовательное исполнение).
* Приказ следующего хода — **отдельный посыльный**; в серию другого хода он
  больше не дописывается (в том числе к серии «сесть в БТР»).
* Исполнение приказа, у которого у того же получателя есть незавершённый
  приказ прошлого хода, приостанавливается до его завершения (барьер
  `operationalOrderWaitsForPredecessor`, причина пишется в лог один раз за ход).

## 5. Бронетехника: лимиты выстрелов по каждому стволу

* «Израсходовано выстрелов» для бронетехники с расчётами считается по
  каждому стволу (`getWeaponShotCount`), а лимит — как сумма лимитов активных
  стволов с живым расчётом.
* Курсовой пулемёт больше не блокирует орудие и наоборот: после выстрела из
  пулемёта кнопки «Стрелковое»/«Орудия» остаются доступными в пределах лимита
  каждого ствола.
