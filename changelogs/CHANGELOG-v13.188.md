# v13.188 — обнаружение оперативных юнитов противника в одиночной кампании

- В одиночной кампании вражеские оперативные юниты создаются необнаруженными, а не раскрываются на старте. После расстановки выполняется однократная начальная проверка обнаружения по общим правилам.
- Операционная карта, её выбор юнитов и список целей для приказов теперь используют общий фильтр видимости: скрытые контакты не показываются; обнаруженные и шумовые контакты отображаются; статические ДОТы сохраняют прежнее правило известных сценарных позиций.
- Проверка обнаружения офлайн-кампании теперь симметрично обрабатывает вражескую пехоту и технику. После движения оперативного ИИ видимость проверяется на новых позициях, а не по устаревшим координатам. Онлайн-обнаружение остаётся на стороне хоста.
- При объединении и разделении бронегрупп сохраняется состояние обнаружения, чтобы группировка не раскрывала скрытую технику.
- Добавлен regression harness `regression_offline_enemy_detection.js`; проверены также выбор и отрисовка оперативных иконок. Версия приложения и service-worker cache обновлены до **v13.188**.
