# v13.175 — Онлайн-бои, параллельное окапывание и маркеры карты

## Изменения

1. Убрана оранжевая отметка собственного шума на иконке оперативного юнита. Обезличенные шумовые маркеры по-прежнему адресуются наблюдающей стороне; собственные онлайн-маркеры не рисуются. Передача шума противнику сохранена.
2. Черновики окопов/расчистки разделены по оперативному гексу, виду работ и имени отряда. Создание второго черновика больше не стирает первый и не использует его лимит. Выполнение приказа применяет только черновик соответствующего отряда. Сохранена совместимость со старым pendingHexEdits. Выдача оставшихся правок учитывает персональную квоту отряда, а не суммарные окопы всех отрядов на гексе; повторная выдача не накапливает очки.
3. На оперативной и тактической картах раскладка иконок общая для обеих сторон. Противники и свои юниты не получают одинаковые центры. В тактической раскладке учитываются только видимые противники; скрытые юниты не меняют размер/расположение видимых иконок. Плашки оперативных имён используют те же центры, что и иконки.
4. Попадание артобстрела/огня по площади отмечается на оперативной карте подписью «Обстрел». Отметка видна в ход обстрела и следующий ход, сохраняется и передаётся оппоненту. Для уже сохранённых обстрелов используются также записи shellNotices. Это маркер цели, не шум источника.
5. Исправлено сопоставление сторон в списках участников сетевого боя. Для одновременно созданных записей одного столкновения выбираются общие метаданные по стабильной паре (ID начала, роль игрока). Гекс, атакующий и направление входа больше не переопределяются по очереди двумя зеркалами/устаревшими оперативными позициями. Старое зеркало согласуется при первом приёме снимка. Миникарта открытого боя использует согласованный гекс.
6. Зеркало включает явно указанных участников даже при запоздавших оперативных координатах; обычные локальные бои по-прежнему требуют присутствия на гексе. Самоисправление isInBattle учитывает имена участников, а не только координаты: оно больше не освобождает участника активного боя из-за рассинхронизации гекса. Прямые вызовы движения также останавливаются, если отряд уже в бою.
7. Изменение только updatedAt в сетевом снимке больше не считается игровым изменением и не вызывает копирование/сохранение/перерисовку всего открытого боя каждые десять секунд.

Исправление доступности онлайн-кнопок поворота из v13.174 включено. Версия, BUILD-маркеры и offline-кэш обновлены до v13.175.

## Ограничения проверки

Сетевая синхронизация проверена локальными снимками обеих сторон и повторным применением через onlineApplyCloudBattles, без подключения к реальной комнате Firebase и без физического Android-устройства. Полученное затем сохранение campaign_save (7).json проверено офлайн: на исходном коде воспроизведено повторное создание зеркала, на исправленном оно отсутствует. Само полное зависание без реальной сети не воспроизведено; подробности — docs/diagnostics/campaign-freeze-replay.md. Сообщение Firestore `Listen transport errored` само по себе не доказывает причину зависания; исправлены обнаруженные ошибки привязки, повторной обработки и движения участников боя. Не удаляйте сохранение или данные приложения для проверки обновления.
