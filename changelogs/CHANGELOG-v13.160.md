# v13.160 — деление развед. взвода A.I.R.F., мотоциклисты при штабе батальона, чистка бронеавтомобилей

Три правки playtest: развед. взвод A.I.R.F. теперь можно делить на отделения
прямо на операционной карте, мотоциклист-разведчик и мотоциклист-посыльный
остались только у штаба батальона BeVe, а «лишних» бронеавтомобилей в игре больше нет.

## 1. ✂️ Развед. взвод A.I.R.F. делится на отделения

В карточке юнита «Развед. взвод» появилась кнопка **«✂️ Разделить на отделения»**,
у отделения — **«🔗 Собрать взвод обратно»**.

* деление даёт по отдельному юниту на каждое отделение: `Развед. отделение №1`,
  `Развед. отделение №2`, `Штаб развед. взвода`;
* у каждого отделения свой гекс, свои ОД, своё обнаружение и своя разведывательная
  миссия — можно отправить два отделения в две разные миссии;
* `Штаб развед. взвода` остаётся при управлении: развед-активом он не считается
  (даже если в шаблоне у него был `reconAssetKey`), активы дают только боевые
  развед. отделения;
* карточки по-прежнему выбираются **на взвод**: выбор, сделанный на любом
  отделении, расходится на все отделения взвода и запоминается в записи взвода
  `campaign.splitPlatoons[<взвод>].cardSelection`;
* сборка возвращает один юнит: порядок отделений, состояние бойцов, дух, иконка,
  тип (`hq`/`recon_platoon`) и карточки восстанавливаются, ОД берутся максимальные
  из отделений, а отделения становятся на гекс штаба;
* деление переживает пересборку оперативных юнитов (`reapplyReconPlatoonSplits`
  возвращает позиции отделений по имени), рации переиндексируются
  (`operationalRadioSnapshot/Restore`), карточка старого юнита закрывается.

## 2. ⚡ Мотоциклисты — только у штаба батальона BeVe

`Мотоциклист-разведчик` и `Мотоциклист-посыльный` убраны из всех взводов — и из
пресета, и из уже начатых походов при загрузке (`applyReconPresetUpdates` в
`js/data.js`, `syncReconPlatoonSquads` в `index.html`: `stripRiders()` /
`ensureRiders()`).

* в пресете BeVe оба мотоциклиста теперь в `squads` юнита `Штаб батальона`;
* повторы не размножаются: `ensureRiders()` добавляет каждого ровно один раз;
* пул разведки тоже стал честным: разведчик-актив один на батальон, а не по
  одному на каждый взвод.

## 3. 🚙 Бронеавтомобили: только Landsverk №1–3

* из разведывательных активов удалён `beve_armored_car` (`js/recon.js`):
  `Бронеавтомобиль` больше не выбирается в списке разведки, а Landsverk —
  обычные отдельные юниты;
* `pruneExtraArmoredCars()` при загрузке батальона и после пересборки юнитов
  удаляет лишние машины: в батальоне остаются только имена из
  `armored_vehicle_platoon` (Landsverk №1–3, без дублей), с карты снимаются
  одиночные машины вне пресета (слитые группы `isGroup`/`vehicleList` не трогаются);
* из шаблонов `js/templates.js` убран `reconAssetKey: "beve_armored_car"`.
