# v13.155 — свой шум не показываем, лишние кнопки орудий убираем

Пятая партия из 39 пунктов по итогам теста (часть 1): маркеры шума (п.20) и
кнопки «Орудия / Миномёты» / «Атака ПТО» (п.27, 31).

## 20. Игрок не видит маркеры шума от собственных отрядов

* Шум — это сведения **противника** о ваших отрядах, а не ваш собственный
  разведывательный признак. Раньше маркер «Шум» ставился и на свою же карту:
  после залпа навесной артиллерии или движения бронетехники игрок видел шумовые
  кружки в своих гексах.
* Теперь маркер шума хранит сторону-адресата (`viewerSide`):
  * свой залп/движение → `viewerSide: 'enemy'` — маркер уходит в облако
    онлайновой партии для соперника и **не рисуется** у игрока;
  * шум вражеской артиллерии → `viewerSide: 'player'` — виден игроку и не
    передаётся сопернику.
* `drawOperationalNoiseMarkers` больше не выбрасывает «чужие» маркеры из
  массива при отрисовке (раньше они удалялись и пропадали из следующей
  синхронизации) — фильтр применяется только к отрисовке.
* Из панели своего отряда в тактике и из карточки своего взвода на оперативной
  карте убраны строки «❗ Шум» / «Шумовая отметка»: свой отряд показывается как
  «🟢 Скрыт», пока противник его не обнаружил.

## 27. Кнопки «Орудия / Миномёты» и «Атака ПТО» — только по способностям

* Панель действий считает типы оружия в расчётах отряда
  (`tacticalCrewWeaponTypesFor` → `squadHasOrdnanceCrew`, `squadHasAntiTankCrew`).
* **«Орудия / Миномёты»** показывается, только если в расчётах есть миномёт,
  противотанковое или танковое орудие. У стрелкового отделения кнопки нет —
  раньше она открывала пустое меню целей.
* **«Атака ПТО по технике»** — только при наличии ПТО/танкового орудия
  (`attackVehicle` всё равно отказывал без него). Дубли кнопок убраны.

## 31. У бронеавтомобилей BeVe нет кнопки «Орудия / Миномёты»

* «Бронеавтомобиль Landsverk 183» определяется семейством машин
  (`vehicleFamilyFor(...).id === 'landsverk'`).
* Их 37-мм Bofors — противотанковое орудие: огонь ведётся через «🚀 Атака ПТО
  по технике», а плитка «Орудия / Миномёты» дублировала её и сбивала с толку.
  Кнопка у этих машин скрыта, «Атака ПТО» осталась.
