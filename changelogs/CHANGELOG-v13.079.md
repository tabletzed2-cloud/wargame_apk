# v13.079 — оперативная карта: фикс UX, HardMode, скрытность

## Что сделано

### 1. Панель размещения на оперкарте не схлопывается (FIX)
**Проблема:** после `autoPlaceUnplacedUnits` и переключения в режим `placePlayer` через `setOpMapMode` панель юнита теряла выделение, и пользователь не видел, какого юнита он переставляет.
**Причина:** `setOpMapMode` всегда сбрасывал `appData.campaign.selectedOpUnit = null`.
**Фикс:** теперь сбрасывается **только** при смене «своей стороны» на чужую (placePlayer ↔ placeEnemy, movePlayer ↔ moveEnemy). При переключении между совместимыми режимами (placePlayer ↔ movePlayer ↔ marker) выделение сохраняется.

### 2. Выбор юнита на оперкарте запоминается (FIX)
Связано с #1: тот же фикс решает обе проблемы. `opPlaceSelect` теперь корректно удерживает выбранного юнита при перерисовке.

### 3. HardMode скрывает ручное управление на оперкарте (NEW)
В HardMode (сложный режим) юниты действуют **только по приказам**. Кнопки «🚶 Перемещение» и «🎯 Обстрел» на оперкарте скрыты через `applyUxPhase`. Дополнительно в `setOpMapMode` — защита: попытка программно переключиться в `movePlayer`/`moveEnemy` через консоль тоже отвергается (с понятным сообщением).
**Файлы:** `index.html` (applyUxPhase + setOpMapMode).

### 4. Талреп-якорь: заезд на холмы смягчён (FIX)
**Проблема:** техника A.I.R.F. с талрепом могла заехать только на гексы с **level<2** на тактической карте, что исключало все гексы с уровнями 0-1 (низины) и 2 (среднегорье), оставляя только level=3 (пики). По факту заехать было почти некуда.
**Фикс:** теперь проверяется `level<=2` — заехать можно на любой гекс, где есть **что-то ниже или равное среднегорью** (т.е. есть куда зацепиться). Только абсолютные пики (все level=3) — закрыты. Также смягчён `tacticalHexHasSublevel2` в `js/hexmaps.js` (level<=2 вместо level<2).
**Проверено:** на карте Валенсия 2 «полностью-пиковых» гекса (5,3 и 6,2) — на них действительно нельзя заехать, что логично.
**Файлы:** `js/hexmaps.js` (tacticalHexHasSublevel2).

### 5. Скрытное движение блокирует подъём на холмы (NEW)
**Проблема:** при `stealthMove` ОД урезаны до 2, а подъём на холм — 3 ОД (пехота) или 4 ОД (с талрепом). Подъём невозможен, но в UI подсвечивались холмы — игрок не понимал, почему нельзя.
**Фикс:** явно запрещён подъём на холм при `stealthMove` в `getOpMoveCost` — возвращается `Infinity` (гекс просто не подсвечивается, понятно без объяснений). Семантически правильно: лебёдка талрепа шумит, несовместима со скрытностью.
**Файлы:** `index.html` (getOpMoveCost).

### 6. BeVe «Аварийный тормоз» → стандартная способность бронеавтомобиля (NEW)
**Изменения:**
- Карточка `Noodrem Аварийный тормоз` удалена из `js/cards.js` (была в общем массиве и в `BEVE_CARDS`).
- В тактическом бою для бронетехники BeVe добавлена кнопка **«🛑 Аварийный тормоз»**.
- Работает только если в бой вошли с предыдущего гекса (т.е. есть куда откатиться) и ещё не использована в этом бою.
- При нажатии: юнит **откатывается на 1 гекс назад** (на гекс, с которого вошёл в бой) **без траты ОД**. До конца своего хода больше не может двигаться (`cantMoveThisTurn = true`).
- Флаг `emergencyBrakeUsed` — кнопка исчезает после использования (разово за бой).
- Помечается в оперданных: `opUnit.col/row` обновляются, чтобы на оперкарте броневик уже был на новом гексе.
- Не работает в HardMode? Сейчас работает в любом режиме (это **оборонительная** способность, не противоречит «orders only»).

**Файлы:** `index.html` (`useEmergencyBrake`, `moveSquad` блокировка, кнопка в UI), `js/cards.js` (удаление карты).

**Тест:** в `regression_v13079.js` 5 тестов на «Аварийный тормоз» (объявление функции, использование prevCol/prevRow, блокировка moveSquad, удаление из cards.js, кнопка в UI только для BeVe-бронетехники).
