# Выпуск v13.061 — пофайловый реестр

## Состав релиза

Выпуск исправляет подсветку стартовой зоны, редактор окопов и уведомления о вражеском окапывании, а также ограничивает дальность 82-мм миномётов пятью тактическими гексами. Сохранены ранее внесённые требования по начальным укреплениям, отступлению и последовательности ходов. Предыдущий накопленный пакет ресурсов и карт отдельно перечислен в историческом реестре [`RELEASE-v13.059.md`](RELEASE-v13.059.md); геометрия конкретных карт в этой версии не менялась.

## Реестр файлов v13.061

| Файл | Изменение |
|---|---|
| `VERSION` | Корневая версия приложения — `v13.061`. |
| `index.html` | Возвращена отрисовка зоны стартового размещения до завершения расстановки; вражеское окапывание больше не создаёт локального сообщения/предложения; ограничения дальности и ОД для огня из миномёта; показ 82-мм дальности в пять гексов на оперативной карте; сохранены редактор и фазы боя. |
