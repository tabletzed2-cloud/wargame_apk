# v13.082 — онлайн тактический бой

1. ПТО и бронетехника не выбирают бонусные карты.
2. Карты можно выбрать после своего размещения, не дожидаясь оппонента.
3. Иконки расчётов бутылкомёта и ампуломёта.
4. БТР: посадка/высадка в бою; десант внутри, если заехали уже погруженными.
5. Враги на тактической карте скрыты, пока не обнаружены.
6. ПТО считает попадание автоматически (движение цели, открытая/пересечёнка).
7. Рукопашная без ОД, автостарт в одном гексе, итог один раз в конце хода; окопы для пехоты как поле.
8. Явный баннер чей ход.
9. Кнопки «Обычный ход» / «Скрытно» вместо мелкой галочки.
10. Маркеры 👁️ / 🥷 обнаружения.
11. Рукопашную нельзя прожать несколько раз за ход.
12. Несколько целей на гексе — кнопки под картой, в списке указан гекс.
13. Отступление оппонента позволяет победителю «Завершить бой».
14. +2 минуты за тактический ход (часы обновляются даже без выбранного отряда).
15. В бою сверху «В кампанию»; «В меню» спрятано за подтверждение.

- autoTacticalDetectionForTurn: d10+mod>6 at end of phase; fire always detected
- own icons 👁️/🥷; enemy drawn only if detected
- opp finish does not mass-retreat remaining; finish uses current destroyed/retreated
