# ⚔️ Онлайн-режим: настройка Firebase (5 шагов, ~5 минут)

Онлайн-матчи работают на **Firebase Firestore** (бесплатный тариф Spark).
Всё, что нужно сделать один раз, — создать проект и вставить конфиг в игру.

## Шаг 1. Создать проект
1. Откройте <https://console.firebase.google.com/> → **Add project** (Добавить проект).
2. Название — любое (например, `wargame-online`). Google Analytics — можно отключить.
3. Нажмите **Create project** → **Continue**.

## Шаг 2. Добавить веб-приложение
1. На главной странице проекта нажмите иконку **`</>`** (Web).
2. Nickname — любой (например, `wargame`). Firebase Hosting — **не** нужно.
3. Нажмите **Register app**.

## Шаг 3. Скопировать конфиг
Firebase покажет блок `const firebaseConfig = { apiKey: "AIza...", authDomain: "...", projectId: "...", ... };` — **скопируйте его целиком**.

## Шаг 4. Создать базу данных Firestore
1. В меню слева: **Build → Firestore Database → Create database**.
2. Location — любое (например, `europe-west`). Режим — **Start in test mode** (для игры между друзьями; тестовый режим живёт 30 дней — после переключите на production с правилами из шага 5).
3. **Enable**.

## Шаг 5. Правила безопасности
Вкладка **Rules** — замените содержимое на (и **Publish**):

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /matches/{code} {
      allow read, write: if true; // игра между друзьями: открытые комнаты по коду
    }
  }
}
```

> ⚠️ Правила открытые: знать код комнаты = читать/писать матч. Для дружеской игры
> это нормально. Если захотите защиту — скажите, сделаю правила с токенами.

## Шаг 6. Вставить конфиг в игру
В файле `index.html`, самый нижний `<script>`-блок (поиск: `ONLINE_CONFIG`), замените:

```js
const ONLINE_CONFIG = {
  firebase: null   // ← сюда
};
```

на

```js
const ONLINE_CONFIG = {
  firebase: {
    apiKey: "AIza...",
    authDomain: "ваш-проект.firebaseapp.com",
    projectId: "ваш-проект",
    storageBucket: "ваш-проект.appspot.com",
    messagingSenderId: "1234567890",
    appId: "1:1234567890:web:abc123"
  }
};
```

(вставьте значения из шага 3).

## Готово
Оба игрока открывают игру → **⚔️ Играть онлайн**:
- Игрок 1: «➕ Создать комнату» → получает код (K7QX) → пересылает другу.
- Игрок 2: «🔑 Войти по коду» → вводит код.
- В лобби: создатель выбирает сценарий, каждый — свою фракцию (должны быть **разные**) и поддержку, оба ставят «Я готов».
- Каждый получает свою карту кампании, размещает юнитов **только в своей зоне** (название сценария → `SCENARIO_PLACEMENT_ZONES` в `js/data.js`), жмёт «✅ Завершить размещение».
