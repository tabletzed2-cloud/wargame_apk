# Боевой модуль — wargame_apk

Браузерная/PWA-игра с оперативной картой, тактическими боями и одиночным ИИ; онлайн-матчи синхронизируются через Firestore. Текущая версия: **v13.200**.

## Локальный запуск

Нужны Python 3 и, для тестов, Node.js 22+ с npm.

```sh
npm ci
python3 -m http.server 8080 --bind 0.0.0.0
```

Откройте `http://localhost:8080/` на своём компьютере либо URL предпросмотра среды разработки. `file://` не подходит для карт, fetch и service worker. Сервер является статическим: сборщик для запуска игры не нужен.

В репозитории **нет Android/Gradle-проекта и команды создания APK**. Проверки ниже проверяют браузер/PWA, а не Android WebView. Если применяется внешняя Android-обёртка, её сборку, подпись и тестирование нужно документировать отдельно.

## Проверки

```sh
npm test                 # синтаксис, целостность сборки и поддерживаемый smoke-набор
npm run test:browser     # Chromium: техника, сохранения/импорт, DOM и реальный offline SW
npm run test:baseline    # ВСЕ legacy-регрессии; ошибка при новом падении
npm run test:all         # ВСЕ legacy-регрессии; ошибка при любом падении
```

`npm ci` устанавливает закреплённые версии парсера, Playwright и portable Chromium. Браузерный runner рассчитан на Linux x64, использует `tar` и включает дополнительные библиотеки из npm-пакета Chromium; произвольный скачиваемый браузер не требуется.

Legacy-набор пока не полностью зелёный. Подтверждённые старые падения перечислены с причинами в `test_harness/known-failures.json`; они **исполняются**, а не пропускаются. Полный машинный отчёт: `node_modules/regression-audit.json`. CI запускает smoke, браузерные проверки и сравнение всех регрессий с baseline.

## Структура

- `index.html` — интерфейс, основная игровая логика, сохранения и онлайн-лобби; постепенное выделение модулей предпочтительнее переписывания всего файла.
- `js/` — каталоги, карты, тактический/оперативный ИИ и специализированные панели.
- `service-worker.js` — обязательный офлайн-кэш всего исполняемого кода и проверка версий.
- `test_harness/` — тесты; `tools/` — проверки и инструменты. Завершающие пробелы в именах этих каталогов удалены в v13.200; старые changelog могут содержать прежние пути.
- `docs/REVIEW_HARDENING.md` — что исправлено по ревью и что остаётся открытым.
- `docs/SAVES_AND_RECOVERY.md` — хранение, импорт и восстановление данных.
- `docs/ONLINE_PROTOCOL.md` — транзакции, ограничения безопасности и план миграции протокола.
- `docs/RULES.md` и `rules.html` — исторический справочник механик и игровая справка; актуальные изменения также смотрите в `changelogs/`.
