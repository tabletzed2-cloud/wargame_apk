Откройте предпросмотр (порт 8001) или `review.html` локально. Слои отключаются по одному.

2. **Лес и кусты:** пересечения на юго-западе (0,8 / 1,8 / 3,13) и юго-востоке (9–11,12–13) — 11 центров с обоими признаками. Сейчас приоритет леса. У краёв проверить forest-10/13/14/15 и bushes-08.

4. **Дорога (розовая):** 3 ветви, узел ветвления в центре. Связи — только соседние гексы. Мосты через воду не добавлялись: дорога, упирающаяся в воду, без амфибии — красный переход.
