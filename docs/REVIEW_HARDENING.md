## Проверки и честные границы

- `npm test`: поддерживаемый smoke-набор и проверка синтаксиса/зависимостей/версий.
- `npm run test:browser`: движение и расход ОД восьми машин; отсутствие перекрытия секторов; DOM-инъекции в рассмотренных местах; сохранность повреждённого JSON; реальный импорт с pagehide/reload; настоящий SW с отказом обязательного ресурса и последующим запуском офлайн.
- В SW-браузерном тесте отключается только огромный список **необязательных** картинок/карт; список executable core, проверка версий и install/activate/fetch остаются настоящими.
- `npm run test:baseline`: исполняет все regression-скрипты, допускает только падения, ранее воспроизведённые на исходном commit 6481224.
- Список старых падений: `test_harness/known-failures.json`. Полный вывод каждого теста сохраняется в `node_modules/regression-audit.json`, в CI — artifact.
- Реальные Android/WebView, production Firebase и аутентификация не проверялись и не развёртывались. Совпадение имён отрядов в онлайн-протоколе по-прежнему требует protocol v2.

Следующие наиболее важные задачи: завершить безопасный DOM-рендер редакторов, внедрить версионированную схему сохранения, затем отдельно выпустить protocol v2 с Auth, стабильными ID и emulator-тестами. Не следует считать перечисленные открытые пункты закрытыми из-за зелёного smoke-набора.
