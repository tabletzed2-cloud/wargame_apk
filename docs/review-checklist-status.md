# Статус исправлений по сводному ревью

## Исправлено

- **1, 20:** проверки ручного движения и видимости действий используют `hardMode.enabled`; обращения к `appData.campaign.hardMode` и запись `c.hardMode = true` удалены.
- **2:** повторная выдача trench/prep points учитывает уже применённые клетки, включая только что применённый черновик. Добавлен `countHexPrepCells` с фильтрацией источника `prep`.
- **3:** `touch-action: none` на оперативном canvas независимо от PointerEvent; завершение перетаскивания больше не сбрасывает это свойство.
- **4, 5:** удалены дубли трёх ID боевых кнопок; состояние свёрнутой панели техники хранится через `safeLocalStorage`.
- **6, 7, 18, 37:** сигнатура панели этапов предотвращает лишний `innerHTML`; учитывает также готовность укреплений и смену DOM-узла. Таймер повторяет установку обработчиков размещения и canvas, если элементы появились позднее.
- **9:** при восстановлении экрана открытое меню приказа перерисовывается, если выбранный отряд существует.
- **11:** убрана вырожденная проверка orders во второй ветке управления deploy-панелью.
- **12:** Hard Mode инициализируется перед запросом открытия связи; автоматическое открытие отложено до следующей задачи и проверяет актуальный экран/этап.
- **13:** вражеская артиллерия отбирает цели только в playable area.
- **14:** при победе облачного состояния синхронизируется источник даже при одинаковой местности/варианте; изменение источника устанавливает `hexChanged`. Источник проигравшей правки не перезаписывает источник победившей.
- **15, 16, 17, 19:** пустой operational tray изначально скрыт; cut-path draft проверяет обе координаты, включая null; Infinity не считается проходимой стоимостью; поля модального окна читаются/записываются с проверкой DOM.
- **21:** подготовленные позиции получают владельца из overlay при применении к тактической карте.
- **22, 38:** отказ размещения объясняет резервирование клетки под вход противника, без показа направления/контура зоны.
- **27, 40:** tabs создаются внутри campaignApp; side panels инициализируются в showOperationalMap до карты.
- **28:** вычисление достижимости снабжения кэшируется по классу мобильности на один renderSupplyPanel; результаты null также кэшируются.
- **29, 39:** удалён opLegacyPanelButtons и относящаяся к нему логика applyHardModeUI.
- **33 (частично):** удалены скрытая btnBattleToMenu, неиспользуемые profile-menu CSS и ранние объявления четырёх дублированных функций. Сохранены последние реализации — те, которые фактически действовали до исправления.
- **36:** вместо 400-мс polling используется MutationObserver атрибутов экранов, с первоначальным обновлением кнопки.
