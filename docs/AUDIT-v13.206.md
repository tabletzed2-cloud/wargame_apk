# Повторная проверка кандидатов и действующих механик — v13.206

> Исторический отчёт. В v13.207 по уточнению пользователя ручное «Скрыться» полностью удалено; отдых у штаба вновь запрещён уже бегущим отрядам, а автоматическое бегство направлено к противоположной от входа противника границе. См. `changelogs/CHANGELOG-v13.207.md`. Ниже описано состояние именно v13.206.

Проверка исходников `index.html` и `js/*.js` (без стороннего Firebase-бандла), HTML-обработчиков, экспортов и тестов. Отсутствие найденных вызовов внутри приложения не является доказательством отсутствия любых внешних обращений через консоль/расширения. Удалены только согласованные старые обработчики движения и отдельные ручные проверки обнаружения.

## 2. «Скрыться»: как работает сейчас

### Интерфейс и результат

- Кнопка показывается у обнаруженного отряда, если он не бронетехника. Общий интерфейс блокирует действия вне своей фазы, при бегстве и других обычных запретах.
- Открывается действующий диалог `showDetectionDialog('hide')`, не удалённый старый `hideSquad`.
- Игрок вручную отмечает условия. Автоматически заранее отмечаются «неподвижен», если отряд не двигался, и большой размер при 10+ бойцах. Остальная местность/наблюдение не определяются этим диалогом по реальной карте.
- Бросок: `d10 + сумма отмеченных модификаторов + карточные модификаторы`. Активная карта «Ночь» без ракеты даёт ещё −2.
- Успех строго при результате **меньше 4**. Устанавливаются `detected=false`, `noiseMarker=false`. `hidden` этим действием не устанавливается.
- При неудаче отряд остаётся обнаруженным.

### Модификаторы диалога

| Условие | Модификатор |
|---|---:|
| Стрелял | +3 |
| Автотранспорт / бронетехника | +2 / +3 (бронетехнике сама попытка запрещена) |
| Сектор под наблюдением противника | +2 |
| Ускоренное движение | +1 |
| Размер от 10 бойцов | +1 |
| Дымовая завеса | −2 |
| Здание/окоп | −2 |
| Неподвижен | −2 |
| Лес/кусты | −1 |
| Разведчик/камуфляж/снайпер | −1 |
| Скрытное движение | −1 |
| Противник ведёт бой на другом направлении | −1 |

Без модификаторов вероятность успеха 30%; с одним отмеченным «неподвижен» — 50%. Это вероятность отдельной попытки, не автоматической проверки обнаружения в конце хода.

### Проблемные ограничения, которые пока НЕ менялись

1. Попытка не расходует ОД и не записывает расход способности за фазу. После неудачи можно открыть диалог и повторять.
2. Сам обработчик исполнения не проверяет фазу/состояние отряда: обычное использование ограничено общей блокировкой кнопок, но отдельный вызов функции может её обойти.
3. В этой ручной попытке нет обязательной проверки соседства наблюдателя, общей клетки, реальной линии видимости и факта стрельбы. Значимые условия выбирает игрок.
4. Поэтому возможно вручную скрыть отряд даже при наличии рядом противника. Фазовое обнаружение и контакт при движении могут затем снова его раскрыть.
5. Это отдельная система от автоматического обнаружения. Простая замена её порога на 8+ перевернула бы смысл проверки: у скрытия хороший результат должен уменьшать обнаружимость.

Для изменения правил необходимо выбрать: оставить ручной инструмент либо сделать автоматическую попытку по реальным условиям карты с ограничением частоты/стоимости. В этой версии поведение сохранено и проверено браузерным тестом: d10=5 с «неподвижен» −2 успешно скрывает без расхода ОД.

## 3. Почему не работала кнопка «К штабу»

- В интерфейсе она оценивалась как обычное `utility`-действие, которое запрещено бегущему отряду. Исполнитель отдыха при этом как раз мог снять бегство и подавление. Теперь выделено действие `regroup`, одинаковое для интерфейса и исполнителя.
- Выбирался первый живой штаб в массиве, а затем проверялся его гекс. Если первый штаб не размещён или его гекс занят врагом, другие штабы не рассматривались. Теперь отбираются подходящие штабы на карте, свой взвод имеет приоритет.
- Сохранены законные причины отказа: чужая фаза, пауза боя, уничтоженный/сдавшийся/покинувший карту отряд, отсутствие доступного штаба, повторный отдых в том же ходу.
- Отдых использует прежнее правило: **мгновенный перенос на гекс штаба**, обнуление остатка ОД, восстановление духа не ниже половины, снятие подавления/бегства. Это не маршрутное перемещение; в v13.206 данный аспект правил не перерабатывался.

## 4. Послебоевое объединение

Пользователь выбрал **только ручное**. Автоматический `mergeTacticalCasualtySquadsAfterBattle` не подключён к завершению боя и в этой версии не подключался.

Конкретные препятствия ручному переносу:

- Номер внутри названия («№1 Бельгийцы») не удалялся при сравнении типов, хотя номер в конце строки удалялся. Исправлено.
- Сравнивался весь объект временных эффектов; различие в использованном заряде/счётчике делало одинаковые отделения несовместимыми. Для ручного переноса сравниваются состав, тип, карты и прочие статические признаки, не расходованные временные счётчики.
- Проверка потерь и вместимости сохранена: донор потерял не менее половины исходного состава; у получателя есть потери и достаточно свободных мест для **всех** выживших донора.
- Перенос только между участвовавшими в бою совместимыми отделениями одного взвода. Расчёты, техника, специальные карточные формирования и бойцы в пути не включаются.
- Численность сохраняется, донор опустошается, его боеприпасы переходят получателю. Повторный перенос невозможен. Автоматического создания бойцов или боеприпасов нет.

Браузерная проверка нажимает настоящую кнопку переноса в послебоевом окне с названиями, соответствующими формату каталога, и проверяет бойцов/патроны до и после.

## 5. Боеприпасы и единственный боец расчёта

Первоначальное замечание уточнено: у ИИ уже был запрет отправлять последнего свободного бойца **отряда**. У игрока и в общем обработчике такого запрета не было. Также один боец расчёта может входить в более крупный отряд: наличие других свободных бойцов ещё не означает наличие замены у его орудия.

Теперь общий исполнитель не позволяет оставить без присутствующего бойца ни отряд, ни назначенный активный расчёт. Отдельно исправлен случай, когда после законного ухода посыльного остальные расчётчики погибают: `isAway` исключается из доступных обслуживающих оружие бойцов до списания ОД и боеприпасов.
