# Сохранения, импорт и восстановление — v13.200

## Хранение

Основной JSON хранится в localStorage под ключом `wargameV10`. Номер исторический: не меняйте его без миграции. `saveData()` возвращает `true` только после успешной записи; при исключении или переполнении — `false` и видимое предупреждение с экспортом резервной копии. Запись одного значения localStorage атомарна: неудачная запись не заменяет предыдущую.

Состояние активного тактического боя находится также в глобальных `actionPoints`, `currentTurn`, `appData.squads`, `appData.map`; обычное сохранение переносит их в запись боя. Поэтому **для установки импортированного JSON нельзя вызывать обычный saveData()**.

## Если загрузка не удалась

Игра не удаляет исходное значение. Устанавливаются `window.__wargameRecoveryPending` и `window.__wargameRecoveryRaw`; автосохранение блокируется. Баннер позволяет скачать исходный JSON. Значения на экране по умолчанию — не восстановленная кампания, продолжать её в этом состоянии не следует.

1. Скачайте резервную копию кнопкой в предупреждении.
2. Попробуйте импорт исправленного или более раннего экспорта.
3. Либо после экспорта используйте явную кнопку «Сбросить данные» в меню.

При переполнении localStorage экспортируйте копию до закрытия вкладки. Удалять данные браузера без экспорта не следует.

## Импорт

`validateImportedData()` выполняет структурные проверки основных контейнеров и отрядов, а также отклоняет ключи, способные изменять прототипы. Это **не полная схема всех игровых полей**: нужна дальнейшая формализация вложенных карт, оружия и записей сетевого протокола.

`installImportedData()`:

1. Проверяет данные, не меняя текущую игру.
2. Копирует прежнее сохранение в `wargameV10.before-import` (предыдущая такая копия заменяется).
3. Записывает импорт непосредственно, без подстановки прежнего Hard Mode и живого боя.
4. Запрещает сохранение через pagehide/beforeunload и перезагружает страницу.
5. Обычная загрузка выполняет существующие миграции.

Если не хватает места даже на резервную копию, импорт отменяется. Сначала экспортируйте данные и освободите место. Файл кампании устанавливается в копию appData; активный бой не открывается автоматически — его можно открыть из списка боёв.

## Ограничения

- Многовкладочная запись одной кампании пока не имеет блокировки/ревизий. Не играйте одну локальную кампанию одновременно в нескольких вкладках.
- Резервная копия перед импортом находится в том же хранилище; это не замена внешнему JSON-экспорту.
- Для очень больших кампаний следующий шаг — версионированная схема и хранение игровых снимков в IndexedDB, со сценариями миграции и отката.
