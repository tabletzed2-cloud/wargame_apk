# v13.081 — стек на гексе, продолжение кампании, без профилей сложности

## 1. Размещение на занятый гекс
В режиме «📌 Размещение» клик всегда ставит выбранный в списке отряд на гекс, даже если там уже стоят другие. Выбор без постановки — кнопка «👆 Выбор отряда».

## 2. Сворачивание приложения
Кампания сохраняется при уходе со страницы (`visibilitychange` / `pagehide` / `pause`). Повторный вход в «Кампания» или после перезапуска WebView продолжает карту, а не выбор фракции/сценария.

## 3. Убраны Новичок / Обычный / Ветеран
Остаётся только переключатель Hard Mode (приказы и связь).
